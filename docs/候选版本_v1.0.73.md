# v1.0.73 候选验证说明

网络 OTA 接收期间进入升级页并显示接收进度；包仍由 SHA256、RSA 签名与官方 A/B OTA 校验。TCP 小响应关闭 Nagle，传输耗时需实机测量。

文件夹单击进入，操作栏上移，路径区缩小，移除文本编辑和容量查询控件；文件图标使用几何形状，避免符号字体缺失。设备信息按固定间距分行，避免长文字叠在其他控件上。

用户报告 720P 视频帧缓存错误 2、格式 14、步幅 2560、高 720。代码中错误 2 对应物理帧内存申请失败。SDK MJPEG 帧数为 1 + extra_frames，本版将额外帧数从 1 改为 0，预期减少一块 1,843,200 字节的连续物理内存；播放器仍在画面绘制完成后归还帧。实际能否连续播放、帧率和内存碎片影响必须上板验证，不能保证 720P 60 fps。

本机定制构建使用 `-ToolboxKeyFile` 和 `-WifiBootstrapFile`，后者为 SSID 和密码各一行；临时私有头文件在构建后清除。公开包不包含这两项凭据。仅在无已保存网络时尝试默认路由器，连接成功由 SDK WLAN 配置机制保存；后台定期刷新保存列表。

普通 OTA 不包含 SPL；工厂 IMG 供用户自行操作 AiBurn。显示布局、无线保存、实际 OTA 速度及视频播放均需目标板验证。
