# D133 控制终端 1.0.190

基于 1.0.189。D133 在 Wi-Fi 取得地址后，通过 192.168.17.4 的 HTTP Date 响应头校时。RTC 保存 UTC，首页显示北京时间。失败后 30 秒重试，成功后每小时校准一次。

首页及全部应用新增「系统设置」。声音卡提供蜂鸣器开关、0–100% 音量和试音，蜂鸣器设置异步保存到冗余 ENV。屏幕检测轮播间隔可在 0.5–10 秒内按 0.5 秒调节，本次开机有效。系统信息沿用原页面。

背光沿用现有 GPIO 控制。屏幕检测沿用纯全屏与实体键。固件包括工厂镜像、签名 OS OTA 和 SHA256 校验清单。未烧录，板上校时、音量与掉电保存待验证。
