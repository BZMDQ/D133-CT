# v1.0.45 BMP 图片优化与验证

- 读取线程与转换线程使用两块批次缓冲和 RT-Thread 信号量交接；第二块缓冲或线程无法创建时回退单缓冲。图片取消时等待读取线程退出，再释放缓冲和关闭文件。
- 常见 RGB555 使用专用 RGB565 转换路径；特殊通道掩码的移位参数在图片头读取后计算一次。
- 图片线程发布完成标志，LVGL 线程消费标志并让图片定时器立即就绪；控件仍由 LVGL 线程更新。
- 每块批读缓冲上限 512 KiB；双缓冲额外占用最多 512 KiB，另需可视区域 RGB565 图像缓冲。申请失败时保留单缓冲回退。

## 手动验证

1. 用 AiBurn 手动烧录 v1.0.45 工厂 IMG。此镜像包含配套 Bootloader 和 DATA 分区；先备份设备配置和数据。禁止自动擦写或烧录。
2. 使用同一张 FAT32 SD 卡和同一张图片，对比 v1.0.44、v1.0.45 打开耗时；分别测试 16 位 RGB555/RGB565、24 位 BGR、32 位及特殊掩码图片，检查色彩、方向、居中和大图裁剪。
3. 测试连续打开、返回后立即重试、正在读取时退出或拔卡，以及内存紧张时是否回退并提示错误。
4. 在屏幕测试页面验证同分辨率 BMP 打开；文件管理和屏幕测试都由 LVGL 线程消费图片完成通知，原定时器保留作为回退。

构建与主机边界模型检查不能证明读取和转换实际并行、颜色正确或时间缩短，以上项目均需要开发板验证。
