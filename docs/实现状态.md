当前工厂镜像为 v1.0.20，`downloads/d13x_d133cbv-hmi-nor_v1.0.20.img` 大小 4,561,408 字节，SHA-256 `4cafb6f7433399e880c66912bfbbae8e31b9e4d927fc9f6e43f97ce78a680d14`。镜像包含配套 SPL/Bootloader、冗余 ENV、OS_A/B、RODATA_A/B 和 DATA。SDK 构建报告 OS 为 1,392,640 字节，小于 2 MiB 槽位；RODATA 为 2,502,656 字节，小于 5 MiB 槽位。此次未生成 v1.0.20 OTA 包；v1.0.18 OTA CPIO 与 v1.0.19 诊断包均不适用于已经安装 v1.0.19 的设备升级。

用户提供的 v1.0.16 上电复位日志报告整机启动 `1.625 sec`；最新 v1.0.18 外部引脚热复位日志报告 `1.630 sec`、SPL 读取 1,380,780 字节耗时 28,658 μs。两者复位条件不同，不可直接比较。最新 HMI 标记为控件129 ms、flush219 ms、render222 ms，均从 app_manager 起算；没有图片打开日志。v1.0.18 已移除显式启用的未用驱动测试命令、延迟创建键盘、批量读取 BMP，并用20 ms预览定时器；整机冷启动和图片耗时仍需上板测量，不能宣称已达1秒。QSPI/NOR 参数保持原配置。

v1.0.19 RT_DEBUG_INIT 诊断 OTA 已通过 SDK 构建、CPIO 主机校验和 RSA 验签，包大小 3,931,136 字节，SHA-256 `ff783f19bb476509175ddb0fa962732368e9b0c760302dbf526971d4e1ca8c0b`。它输出每个 RT-Thread 初始化函数及早期阶段耗时；UART 大量日志会增加启动时间，profile 仅用于定位，不是生产固件。安装后设备版本为1.0.19，后续正式 OTA 必须使用更高版本。

板载 Wi-Fi 芯片为 RTL8723DS。当前 Luban-Lite Realtek 支持仅选择 RTL8733/RTL8189，缺少匹配的 RTL8723DS SDIO 驱动和 E907F 库，所以 v1.0.20 没有启用无线功能；详细缺失项见 `docs/无线与蜂鸣器集成.md`。PWM 蜂鸣、协议编译、工具箱源代码变更均未做真实板级/网络验收。新的工具箱 EXE 尚未重新打包；当前已发布的 0.8.36 不会显示新设备消息。

所有代码基于本地 Luban-Lite 接口；没有修改 `bsp/` 驱动源码，也没有写实际 Flash 地址。v1.0.20 增加应用层蜂鸣与设备消息模块，工厂镜像构建不代表蜂鸣器或 TCP 的板级验收。诊断 profile 仅在 `RT_DEBUG_INIT` 打开时为 RT-Thread board/device/component 初始化输出计时，并不改变生产 profile 的启动路径。

尚未完成实机验收：首页不显示状态胶囊、设备总览卡片打开独立详情页、5×3 启动器布局、顶栏/Logo 间距、新版完整启动速度、SD 图片各格式颜色/内存占用、全屏触摸返回、NOR 原频率冷启动稳定性、LVDS 时序、GT911 触摸、SD 插拔、RMII 链路/DHCP、Wi-Fi、蜂鸣、看门狗触发、A/B 试启动与回退，以及工具箱对板端 TCP 的真实传输。本次没有使用 AiBurn、烧录、擦除 NOR 或改变开发板状态。Bootloader 预启动黑屏已关闭，OS 仍初始化 LVDS；v1.0.20 工厂镜像供用户自行用 AiBurn 首次部署。日常 OTA 不含 SPL/Bootloader。UART `[boot_time]` 数值只覆盖 RT-Thread app 初始化到显示 flush，不等于完整上电时长；完整 1 秒验收需上板外部测量。

RSA私钥 `keys/development_private.pem` 是仅供开发的本地测试密钥。量产必须改用受控密钥，并配置TLS/证书或TLS设备身份认证；当前TCP OTA按用户要求运行在局域网明文链路，由签名和屏幕确认保护升级授权。
