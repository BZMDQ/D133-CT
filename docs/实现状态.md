当前工厂镜像为 v1.0.22，`downloads/d13x_d133cbv-hmi-nor_v1.0.22.img` 大小 4,262,400 字节，SHA-256 `c03ae1ecb699acaee776cc2b8a4e00d39e8271f2bc02413c9cf65d2b9a9991f8`。镜像包含配套 SPL/Bootloader、冗余 ENV、OS_A/B、RODATA_A/B 和 DATA；本次未发布日常 OTA。v1.0.22 只完成 SDK 构建，没有板上启动/串口/图片预览数据。

用户提供的 v1.0.20 外部引脚热复位日志报告 `Startup time: 1.632 sec`；SPL 读取 1,389,240 字节耗时 28,834 μs；framebuffer 在 1.375 秒分配；HMI 标记控件127 ms、flush218 ms、render221 ms。此前 v1.0.18 同类复位为 1.630 秒，差 2 ms，未显示整机速度改善。需要 RT 初始化逐项耗时才能继续定位 1.375 秒前的时间；QSPI/NOR 参数保持原配置。

v1.0.19 RT_DEBUG_INIT 诊断 OTA 已通过 SDK 构建、CPIO 主机校验和 RSA 验签，包大小 3,931,136 字节，SHA-256 `ff783f19bb476509175ddb0fa962732368e9b0c760302dbf526971d4e1ca8c0b`。它输出每个 RT-Thread 初始化函数及早期阶段耗时；UART 大量日志会增加启动时间，profile 仅用于定位，不是生产固件。安装后设备版本为1.0.19，后续正式 OTA 必须使用更高版本。

板载 Wi-Fi 芯片为 RTL8723DS。当前 Luban-Lite Realtek 支持仅选择 RTL8733/RTL8189，缺少匹配的 RTL8723DS SDIO 驱动和 E907F 库，所以 v1.0.22 仍未启用无线功能；详细缺失项见 `docs/无线与蜂鸣器集成.md`。用户提供的 v1.0.20 UART 日志验证了当时的启动和 LVGL 首帧，但未验证本次 UART0 命令、图片裁剪或 CMA 余量。该日志还报告 `/data` LittleFS 挂载失败；`/sdcard` 初始挂载失败后检测到插卡，但未见挂载成功行。

所有代码基于本地 Luban-Lite 接口；没有修改 `bsp/` 底层驱动，也没有写实际 Flash 地址。v1.0.22 通过板级静默 console 设备关闭 RT 控制台输出；UART0 驱动重新启用，只用于屏幕代号协议；FinSH/MSH 与 ULOG 输出仍关闭。BootROM/SPL 打印路径没有修改。用户已自行修复上电进入 BROM，本次未改 PA0/BOOT 配置。编译结果尚未上板验证。

尚未完成实机验收：v1.0.22 UART0 的 `CS000`/`CS001` 应答、JPG/PNG MPP 裁剪、BMP 16/24/32 位颜色、图片 CMA 余量、触摸返回、同条件冷启动与 1 秒目标、LVDS/GT911、SD 插拔和挂载、`/data` LittleFS、RMII/DHCP、蜂鸣、看门狗/A/B 回退，以及工具箱对板端 TCP 的真实传输。CS001 仍未配置；待完整 LCM 时序/排线资料和 ATMXT1066TD 驱动依赖。没有连接或操作硬件，未烧录/擦除 Flash，也没有发布本版本 OTA。UART `[boot_time]` 在静默正式配置中不输出；整机时长仍需外部计时验证。

RSA私钥 `keys/development_private.pem` 是仅供开发的本地测试密钥。量产必须改用受控密钥，并配置TLS/证书或TLS设备身份认证；当前TCP OTA按用户要求运行在局域网明文链路，由签名和屏幕确认保护升级授权。
