当前工厂镜像为 v1.0.24，downloads/d13x_d133cbv-hmi-nor_v1.0.24.img 大小 4,270,592 字节，SHA-256 ea3b6268a188f958e4a9ac81533863fd05f02da27189dacaa6c8d5e37f4409b9。镜像包含配套 SPL/Bootloader、冗余 ENV、OS_A/B、RODATA_A/B 和 DATA；没有生成日常 OTA。Luban-Lite SDK 构建通过；CS001 MIPI 出图、lane/极性和 UART 实收发仍待板测。

用户提供的 v1.0.20 外部引脚热复位日志报告 `Startup time: 1.632 sec`；SPL 读取 1,389,240 字节耗时 28,834 μs；framebuffer 在 1.375 秒分配；HMI 标记控件127 ms、flush218 ms、render221 ms。此前 v1.0.18 同类复位为 1.630 秒，差 2 ms，未显示整机速度改善。需要 RT 初始化逐项耗时才能继续定位 1.375 秒前的时间；QSPI/NOR 参数保持原配置。

v1.0.19 RT_DEBUG_INIT 诊断 OTA 已通过 SDK 构建、CPIO 主机校验和 RSA 验签，包大小 3,931,136 字节，SHA-256 `ff783f19bb476509175ddb0fa962732368e9b0c760302dbf526971d4e1ca8c0b`。它输出每个 RT-Thread 初始化函数及早期阶段耗时；UART 大量日志会增加启动时间，profile 仅用于定位，不是生产固件。安装后设备版本为1.0.19，后续正式 OTA 必须使用更高版本。

板载 Wi-Fi 芯片为 RTL8723DS。当前 Luban-Lite Realtek 支持仅选择 RTL8733/RTL8189，缺少匹配的 RTL8723DS SDIO 驱动和 E907F 库，所以 v1.0.23 仍未启用无线功能；详细缺失项见 `docs/无线与蜂鸣器集成.md`。用户提供的 v1.0.20 UART 日志只验证了当时的启动和 LVGL 首帧，未验证本次 UART0 RX/TX、CS001 LVDS 或 CMA 余量。该日志还报告 `/data` LittleFS 挂载失败；`/sdcard` 初始挂载失败后检测到插卡，但未见挂载成功行。

HMI 业务仍使用 Luban-Lite/RT-Thread 接口。v1.0.24 在工程 overlay 中并编 LVDS 与 MIPI-DSI 驱动；aicfb probe 前读取官方 ENV hmi_screen，选择 CS000/LVDS 或 CS001/MIPI，并同步切换 PD18–PD27 引脚复用。CS001 使用 EK79202D 1280×800、72.4 MHz、4-lane RGB888 候选 timing 和 DSI Video Pulse；只发送资料列出的标准 DCS 初始化命令。lane strap、FPC mapping/polarity 和模组电源/背光时序未在 PDF 中确认，必须上板验证。屏幕代号仍通过官方 ENV 更新并软件重启。UART0 RX 队列修正沿用 v1.0.23；用户已手动烧录 v1.0.22 的无应答问题因此需用 v1.0.24 上板复测。上电进入 BROM 问题已由用户修复，本次未改 PA0/BOOT 硬件路径。

尚未完成实机验收：v1.0.24 启动 profile 行、CS000/CS001 UART RX/TX、CS001 MIPI 1280×800 出图、lane strap/polarity/颜色、软件重启切换、背光与冷启动、图片 CMA 余量、同条件冷启动与 1 秒目标，以及原有 SD、RMII、蜂鸣、看门狗/A/B OTA/工具箱验收。CS001 触摸按用户要求暂时禁用，ATMXT1066TD 驱动/config 后续再补。没有自动烧录/擦除 Flash，也未生成本版本日常 OTA。
