当前工厂镜像为 v1.0.26，downloads/d13x_d133cbv-hmi-nor_v1.0.26.img 大小 4,270,592 字节，SHA-256 2946ce672651c73b1b287f0b2715fe0acbb59fb0d827917e77194bf9acde88ac。镜像包含配套 SPL/Bootloader、冗余 ENV、OS_A/B、RODATA_A/B 和 DATA；没有生成日常 OTA。Luban-Lite SDK 构建通过，GT911 名称健康检查、周期复位停止、UART 实际收发仍待板测。

用户提供的 v1.0.20 外部引脚热复位日志报告 `Startup time: 1.632 sec`；SPL 读取 1,389,240 字节耗时 28,834 μs；framebuffer 在 1.375 秒分配；HMI 标记控件127 ms、flush218 ms、render221 ms。此前 v1.0.18 同类复位为 1.630 秒，差 2 ms，未显示整机速度改善。需要 RT 初始化逐项耗时才能继续定位 1.375 秒前的时间；QSPI/NOR 参数保持原配置。

v1.0.19 RT_DEBUG_INIT 诊断 OTA 已通过 SDK 构建、CPIO 主机校验和 RSA 验签，包大小 3,931,136 字节，SHA-256 `ff783f19bb476509175ddb0fa962732368e9b0c760302dbf526971d4e1ca8c0b`。它输出每个 RT-Thread 初始化函数及早期阶段耗时；UART 大量日志会增加启动时间，profile 仅用于定位，不是生产固件。安装后设备版本为1.0.19，后续正式 OTA 必须使用更高版本。

板载 Wi-Fi 芯片为 RTL8723DS。当前 Luban-Lite Realtek 支持仅选择 RTL8733/RTL8189，缺少匹配的 RTL8723DS SDIO 驱动和 E907F 库，所以 v1.0.23 仍未启用无线功能；详细缺失项见 `docs/无线与蜂鸣器集成.md`。用户提供的 v1.0.20 UART 日志只验证了当时的启动和 LVGL 首帧，未验证本次 UART0 RX/TX、CS001 LVDS 或 CMA 余量。该日志还报告 `/data` LittleFS 挂载失败；`/sdcard` 初始挂载失败后检测到插卡，但未见挂载成功行。

HMI 业务仍使用 Luban-Lite/RT-Thread 接口。v1.0.24 接入的 CS000 LVDS / CS001 MIPI 双接口保持不变。v1.0.25 移除了 /data 挂载失败作为看门狗健康条件；用户在 v1.0.25 上仍报告约 15 秒周期复位。排查后确认 CS000 触摸 profile 使用显示标签 GT911，而 SDK 注册设备名为小写 gt911；RT-Thread 名称区分大小写，导致健康检查一直失败。v1.0.26 给 profile 增加独立 touch_device 字段，健康检查按 gt911 查找，串口仍回报 TOUCH=GT911。UART0 维持同步启动 READY 和线程轮询接收。

尚未完成实机验收：v1.0.26 周期复位是否停止、UART0 READY/CS000/CS001 RX/TX、CS001 ILI9881C MIPI 800×1280 出图、触摸识别、软件重启切换、lane strap/polarity/颜色、背光与冷启动、/data LittleFS 挂载及持久化、图片 CMA 余量、1 秒启动目标，以及 SD、RMII、蜂鸣、A/B OTA/工具箱验收。没有自动烧录/擦除 Flash，也未生成本版本日常 OTA。

RSA私钥 `keys/development_private.pem` 是仅供开发的本地测试密钥。量产必须改用受控密钥，并配置TLS/证书或TLS设备身份认证；当前TCP OTA按用户要求运行在局域网明文链路，由签名和屏幕确认保护升级授权。
