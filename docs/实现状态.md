当前工厂镜像为 v1.0.21，`downloads/d13x_d133cbv-hmi-nor_v1.0.21.img` 大小 4,250,112 字节，SHA-256 `d6cacd79cc56b24b3b8c50c2a4154a6abfaef5b8b1d31f9ae2ec4820d2760f4c`。镜像包含配套 SPL/Bootloader、冗余 ENV、OS_A/B、RODATA_A/B 和 DATA。SDK 构建报告 OS 为 1,081,344 字节，小于 2 MiB 槽位；RODATA 为 2,502,656 字节，小于 5 MiB 槽位。相较 v1.0.20 OS/镜像减少 311,296 字节；按先前 47,050 KB/s 读取率推算，读取量约少 6–7 ms，尚无 v1.0.21 板上计时。此次未生成 v1.0.21 OTA 包。

用户提供的 v1.0.20 外部引脚热复位日志报告 `Startup time: 1.632 sec`；SPL 读取 1,389,240 字节耗时 28,834 μs；framebuffer 在 1.375 秒分配；HMI 标记控件127 ms、flush218 ms、render221 ms。此前 v1.0.18 同类复位为 1.630 秒，差 2 ms，未显示整机速度改善。需要 RT 初始化逐项耗时才能继续定位 1.375 秒前的时间；QSPI/NOR 参数保持原配置。

v1.0.19 RT_DEBUG_INIT 诊断 OTA 已通过 SDK 构建、CPIO 主机校验和 RSA 验签，包大小 3,931,136 字节，SHA-256 `ff783f19bb476509175ddb0fa962732368e9b0c760302dbf526971d4e1ca8c0b`。它输出每个 RT-Thread 初始化函数及早期阶段耗时；UART 大量日志会增加启动时间，profile 仅用于定位，不是生产固件。安装后设备版本为1.0.19，后续正式 OTA 必须使用更高版本。

板载 Wi-Fi 芯片为 RTL8723DS。当前 Luban-Lite Realtek 支持仅选择 RTL8733/RTL8189，缺少匹配的 RTL8723DS SDIO 驱动和 E907F 库，所以 v1.0.21 没有启用无线功能；详细缺失项见 `docs/无线与蜂鸣器集成.md`。用户提供的 v1.0.20 UART 日志验证了启动和 LVGL 首帧，但未验证蜂鸣器、Wi-Fi、工具箱 TCP 或 OTA。该日志还报告 `/data` LittleFS 挂载失败；`/sdcard` 初始挂载失败后检测到插卡，但未见挂载成功行。

所有代码基于本地 Luban-Lite 接口；没有修改 `bsp/` 底层驱动，也没有写实际 Flash 地址。v1.0.21 通过板级静默 console 设备在驱动初始化前关闭 RT 控制台输出，FinSH/MSH 线程与 RT UART0 驱动在生产 profile 中关闭；HMI 调试格式化在正式构建时编译为空。独立诊断 profile 保留串口输出。BootROM/SPL 的打印路径没有修改。静默配置和构建结果尚未上板验证。

尚未完成实机验收：首页不显示状态胶囊、设备总览卡片打开独立详情页、5×3 启动器布局、顶栏/Logo 间距、v1.0.21 静默串口结果、同条件冷启动与完整 1 秒目标、SD 图片各格式颜色/内存占用、全屏触摸返回、NOR 原频率稳定性、LVDS 时序、GT911 触摸、SD 插拔及最终挂载、`/data` LittleFS、RMII 链路/DHCP、Wi-Fi、蜂鸣、看门狗触发、A/B 试启动与回退，以及工具箱对板端 TCP 的真实传输。用户提供的日志确认 v1.0.20 在板上运行并显示 LVGL；v1.0.21 仅完成 SDK 构建。本次没有连接或操作硬件。日常 OTA 不含 SPL/Bootloader；尚未生成 v1.0.21 OTA。UART `[boot_time]` 在静默正式配置中不输出；整机时长仍需板上 UART 以外的计时方式验证。

RSA私钥 `keys/development_private.pem` 是仅供开发的本地测试密钥。量产必须改用受控密钥，并配置TLS/证书或TLS设备身份认证；当前TCP OTA按用户要求运行在局域网明文链路，由签名和屏幕确认保护升级授权。
