# v1.0.64 STA 网络设置

本版关闭设备热点 AP：无线模块只设置 STA 客户端模式，不读取已保存的热点配置、不调用 AP 启停接口，网络页面不再显示热点 SSID/密码或启停按钮。SDIO 无线 STA、路由器自动连接、附近 Wi-Fi 扫描、最多五组已保存网络保持可用。旧 DATA 中遗留的 AP 配置文件保留但不再读取。

将有线 IPv4、STA Wi-Fi、扫描及保存网络、TCP 状态整合到一个可滚动页面。页面每 200 ms 更新 5000 监听状态和 Wi-Fi STA 地址。页面入口：主页“网络设置”。

SDK OS 编译成功；OTA CPIO、RSA/SHA256 签名和工具箱端口默认值已检查。实板 STA 连接、扫描、TCP 访问、AP 确认停止、视觉和触摸尚未验证。端口统一为 TCP 5000；不同网段需先使电脑与板卡网络互通。公开镜像不含本机 Wi-Fi 密码；DATA 明文配置保留在设备上。OTA 需已安装新版 A/B 分区，工厂烧录可能初始化 DATA，操作前备份。
