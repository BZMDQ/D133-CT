# 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 工厂镜像分区范围错误 | 查看 `partition.json`；确认 8 个分区总计 15.75 MiB，保留 256 KiB，所有边界 64 KiB 对齐。 |
| CPIO 预检失败 | 确认是 SDK 生成的 `ota.cpio`，仅含 `ota_info.bin`、`d13x_os.itb`、`rodata.fatfs`，包长与 `size` 一致；使用 `prepare_ota.py` 修复 SDK 回填 size 遗漏的校验字段。 |
| 签名失败 | 确认 `.sig` 对应当前完整 CPIO，使用与 `/rodata/hmi/ota_public.pem` 成对的私钥；不要对压缩包或 JSON 元数据签名。 |
| OTA 报版本错误 | CPIO 版本必须是严格递增的三段数字版本；同步更新固件宏和 `image_cfg.json`，重新编译/签名。 |
| SD 未就绪 | 检查 FAT32、SDMC1 pinmux、PC6 检测、`mount sd1 to /sdcard` 和 `/sdcard/UPDATE` 路径。 |
| TCP 无法连接 | 检查网口/RTL8201F、PHY地址 1、RMII/CLK_OUT2、netdev IP、Windows 防火墙和端口 8899。 |
| TCP 已上传但未确认 | 开发板需在 60 秒内允许；端口会在升级后重启期间断开。重新连接后检查运行版本、OS槽和 health 状态。 |
| 新系统看门狗复位 | 看 UART0 日志；确认 LVGL GUI线程启动、GT911设备名、`/rodata` 和 `/data` 挂载以及两者槽位匹配。Bootloader 连续试启动失败后应同步回退 OS/RODATA。 |
| 旧系统启动但资源异常 | 检查 ENV 的 `osAB_now/next` 与 `rodataAB_now/next`；回退实现必须成对切换。确认 RODATA A/B 的 FATFS 容量均大于镜像。 |
| 开机仍显示旧色块测试画面 | 旧 v1.0.0 SDK 配置启用了 `AIC_DISP_COLOR_BLOCK`。当前工厂镜像为 `downloads/d13x_d133cbv-hmi-nor_v1.0.23.img`；用户需手动用 AiBurn 烧录。若仍看到色块，先确认 AiBurn 选择的镜像路径和烧录结果，再查看显示配置是否为 `AIC_DISP_BLACK_SCREEN=y`、`AIC_DISP_COLOR_BLOCK` 未启用。 |
| 中文显示为空白或方框 | 检查 `/rodata/hmi/fonts/NotoSansSC-HMI.ttf` 是否存在、RODATA 槽是否为与 OS 配对的版本，以及 defconfig 是否启用了 `LPKG_USING_FREETYPE`。字体加载失败会阻止健康确认，使 Bootloader 执行 A/B 回退。 |
| SD 图片无法预览、偏色或内存不足 | v1.0.23 中 BMP 只分配屏幕可视窗口缓冲并逐行读取；JPG/JPEG、PNG 使用 SDK MPP 裁剪窗口，保留原始像素尺寸，不缩放。JPEG/PNG 压缩输入上限为 4 MiB，PNG 受 SDK 800 万像素和硬件解码范围约束。BMP 支持 16/24/32 位 BI_RGB 及 16/32 位 BI_BITFIELDS。确认 SD 卡挂载到 `/sdcard`、文件实际格式与扩展名一致；正式固件不输出 `[image_preview]` 日志。当前尚未板上验证颜色、裁剪边缘及 CMA 余量。 |
| 屏幕代号串口没有应答 | v1.0.22 已知 RX 线程按固定块读取可能没有消费短帧；v1.0.23 改为按 RX 回调字节数读取，并在 UART0 启动时打印 `READY` profile 行。确认系统信息显示 v1.0.23，USB-UART 为 3.3 V TTL、115200/8N1，电脑 TX 接 UART0 RX/PA1，TX/RX 交叉并共地。发送命令后 CS001 会重启；若看不到启动行，仍需确认 OS 是否启动及 UART0 RX 接线。 |
| CS001 重启后黑屏/颜色异常 | `hmi_screen=CS001` 选择 1280×800 EK79202DA 候选时序。确认模组 strap 实际选择 LVDS、RES=1280×800、8-bit mapping 与 D133 单链路 lane/polarity 一致；必要时串口发 `CS000` 恢复并重启。CS001 触摸暂未启用。当前时序和映射尚未板测。 |
| 1 秒启动目标未达到 | 本版关闭 Bootloader 预启动黑屏、将 ULOG 降为 Warning、复用 FreeType 字体，并关闭 HMI 未用的 CAN/音频/TSEN/GPAI 驱动。仍须实测；UART `[boot_time]` 仅记录 RT-Thread app 初始化到首帧/flush，不含 BootROM、SPL 和 Bootloader。请从上电沿测到首页可触摸，并连续冷启动 10 次。QSPI 保持 100 MHz、CPU 480 MHz、AXI/AHB 200 MHz；未核实 NOR 料号并做边界测试前不要超频。 |
| SDK 命令行出现 `python3 not recognized` | 通过工程 `scripts/build.ps1` 构建；该脚本把 SDK Python38、RISC-V 工具链和 SDK host utilities 放入 PATH。 |
| `scons -j8` 在 Windows 挂起 | 检查 pywin32 worker 警告和遗留 `cp.exe/echo.exe` 子进程；保留输出后用 `-Jobs 1` 重建。 |
