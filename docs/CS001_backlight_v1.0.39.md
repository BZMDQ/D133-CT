# CS001 背光检查

v1.0.39 在 ILI9881C-04 初始化前由 SDK panel helper 拉高 PE.13，面板命令完成后再次调用背光使能。编译可确认调用已进入镜像，但无法证明 PE.13 到模组的板级网络有效。

WJ101E5TAAUMNG10# 图纸将 LED 供电引脚列为 CON1 的 VLED+（39/40 脚）和 VLED−（31/32 脚），而 PE.13 是 D133 的逻辑使能脚。上板若仍无背光，请测量 PE.13 电平，并核实 VLED+/VLED− 是否连接到合适的 LED 恒流升压电源。不可将 GPIO 直接接到 LED 电源脚。

验证步骤：人工烧录工厂 IMG 后选择 CS001，检查串口 READY、PE.13 高电平、VLED 电压/电流以及 DSI lane 活动。只有电源和复位接线确认后，再调整极性或初始化时序。本版未执行实机烧录或电气测量。
