# v1.0.57 视频播放

首页点击“视频播放”，在文件管理器选择 SD 卡中的 AVI 文件，然后点击“打开 / 读取”。播放器自动读取和解码，左上角可返回或暂停、继续。解封装和解码使用 Luban-Lite 的 aic-player、AVI 解封装及硬件 JPEG 解码；文件读取和解码在后台线程，LVGL 控件由界面线程操作。

首版输入限制：AVI 容器、MJPEG 视频、无音频、最大 640×480、宽度为偶数。建议 15 帧/秒；这只是转换建议，实际可播放帧率和内存余量必须在板上测量。其他 AVI 编码及带音轨文件会显示错误。若内存不足请进一步降低分辨率或帧率。

Windows 已安装 FFmpeg 时，在 PowerShell 7 中执行：

```powershell
.\scripts\convert_video.ps1 -InputFile 'D:\video\input.mp4' -OutputFile 'D:\video\output.avi'
```

转换需要外部 FFmpeg，脚本不会覆盖现有输出。将 output.avi 复制到 FAT32 SD 卡。播放器仅支持 /sdcard/ 下路径，完整路径不足 128 字节；文件和目录名称需兼容当前 SDK 的 FATFS 编码。转换脚本已检查语法，本机构建环境未发现 FFmpeg，尚未进行转换实测。

OS 构建成功；OS 3006464 字节小于 3392 KiB 槽，资源 3178496 字节小于 3904 KiB 槽。签名 OTA 通过 CPIO、损坏与 SPL 映射防护和 RSA 验证，只支持已有新分区布局且版本低于 1.0.57 的设备。工厂烧录会影响 DATA 前请备份。本机定制包含默认 WiFi 配置，公开包不含该配置。板上视频解码、色彩、触摸、帧率、长时间稳定性和 OTA 尚未验证。
