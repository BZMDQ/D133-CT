# v1.0.54 无线卡死排查版

针对 v1.0.52 主页短暂可触摸后卡住、约 15 秒看门狗复位的现象，使用 SDK 自带独立 SDIO 接收线程，避免在 SDIO 中断线程持锁期间执行完整接收流程，并将中断线程栈由 512 字节调整为 4096 字节。保留看门狗和 A/B 健康检查；故障根因和无线 STA/AP 稳定性尚待实机确认。

本机定制镜像包含无线配置信息，仅用于本机部署；公开镜像不携带默认路由器密码。首次烧录和现有数据的保存请按此前新分区布局说明操作；不得从旧分区布局跨版 OTA。可由使用者手动用 AiBurn 烧录工厂 IMG。启动后观察至少数分钟并尝试主页触摸、STA 连接、AP、TCP OTA；如果仍复位，请提供重启前的现象与串口复位日志。

编译：Luban-Lite OS，编译成功；芯片、SDIO、电源和实际无线通信未经本次实机验证。
