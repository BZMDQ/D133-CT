# v1.0.59 视频启动诊断与缓存顺序

用户反馈同一 AVI 视频在 v1.0.57 可以播放，v1.0.58 提示解码器启动失败。静态比对显示两版播放器源码和解码配置相同；目前没有设备端失败调用的详细记录，不能确认根因。

排除的风险：v1.0.58 在调用 SDK 播放器启动前就分配视频交换缓冲并把尺寸发布给界面，界面可能同时分配 DMA 显示缓冲，与解码器抢占内存。v1.0.59 改为先由官方 aic-player 启动并取得首帧，再申请交换缓冲并通知 LVGL 创建显示缓冲；分配失败时分别提示启动失败或首帧缓冲失败。启动错误显示 SDK 返回值、分辨率和失败后的 RT-Thread 系统堆空闲量；此数值不代表 DMA/CMA 内存。

使用同一视频在设备文件管理器打开，确认画面、暂停、继续、返回，重复打开并观察是否稳定。若仍失败，请拍摄完整错误界面，记下返回码、系统堆空闲及分辨率。实际解码性能、内存分配和根因尚未上板确认。

SDK OS 编译成功，OS 和资源均符合当前 A/B 槽位。签名 OTA 通过 CPIO 成员、SPL 映射拒绝和 RSA/SHA256 检查，安装的工具箱客户端可识别 v1.0.59 包；TCP 传输、设备写入和回滚尚未实测。OTA 适用于已部署新分区布局、版本低于 1.0.59 的设备，签名文件与 CPIO 放同一目录。工厂烧录可能初始化 DATA，先备份。公开镜像不含本机路由器密码。
