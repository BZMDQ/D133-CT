# 文件管理与图片预览

文件管理页采用左侧位置栏、顶部地址及目标路径、操作工具栏、文件列表和右侧文本预览区。选择列表项后按“打开 / 读取”进入文件夹、打开图片或读取文本；“SD 卡”和“上一级”用于目录导航。复制、重命名、新建文件夹使用目标路径框；删除和文本保存有确认提示。目录列表沿用现有 32 项上限，超出时显示截断提示。

BMP 可见区域在文件中连续、且行无填充时，最多四行合并读取；其他情况逐行读取。额外缓冲分配失败时自动回退逐行，输出仍按原像素居中或裁剪。文件管理和屏幕测试共用图片预览线程；JPEG/PNG 继续使用 SDK MPP 解码，本次未修改其解码算法。上板前不能推断具体耗时改善。

## 上板验证

使用同一张 FAT32 卡和同一组正向、倒向、带行填充及大于屏幕的 16/24/32 位 BMP，检查颜色、方向、居中及裁剪，并对比打开时间；同时检查 JPEG/PNG。分别测试文件浏览、进入目录、上一级、复制、重命名、删除、新建文件夹、文本读取与保存；再次进入屏幕测试图片页，确认匹配分辨率和返回键。GUI、SD 兼容性及实际速度尚未在板上验证。
