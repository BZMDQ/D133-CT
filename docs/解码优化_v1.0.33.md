# 图片解码优化

文件管理与屏幕测试共用图片预览工作线程。标准 16 位 RGB565 BMP 直接复制可见行，标准 RGB555 使用位扩展，标准 32 位 RGB 掩码按字节转换；其他 BMP 掩码保留通用转换。屏幕尺寸裁剪、倒序 BMP、行填充和内存回退沿用现有处理。

RGB555 和 RGB565 快速路径对全部 65536 个输入像素分别与原算法比较通过。OS 构建通过；这不等同于开发板显示、色彩或性能验收。

JPEG/PNG 仍由 SDK MPP 解码，已有 RGB565 输出直接复用。暂未修改官方 MPP 输出格式或宣称 JPEG/PNG 解码提速。请使用相同 SD 卡和图片，在前后版本上分别记录从打开操作到画面稳定的时间，并检查 BMP/JPEG/PNG 的颜色、方向、裁剪、透明度、内存不足及返回操作。
