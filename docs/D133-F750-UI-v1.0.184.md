# D133 控制终端 1.0.184

基于 1.0.183 优化 F750 风格界面。首页按字库行高安排时钟和日期，SSID 与 IP 独立成行。文件管理、网络设置、固件升级、设备信息、系统日志和屏幕支持使用可换行的应用卡片。文件名过长时用省略号，详情文本可纵向滚动。输入键盘弹出时，当前输入框滚动到键盘上方。

全屏检测和板载按键沿用 1.0.183。LEFT 进入，UP／DOWN 切换，RIGHT 退出。

## 固件

- D133-F750-UI-v1.0.184.img 是工厂镜像，沿用 1.0.183 的 Bootloader。
- D133-F750-UI-v1.0.184.cpio 与同名 .cpio.sig 是一组 OS OTA 文件。配套 JSON 和 SHA256SUMS.txt 可核对版本、大小及哈希。

工厂镜像与 OTA 由同次固件构建生成。此版本未烧录，实体屏幕尚未验证。
