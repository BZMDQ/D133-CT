# v1.0.34 BMP 解码路径

24 位 BI_RGB 和标准通道顺序的 32 位 BMP 使用专用 BGR 到 RGB565 行转换，避免每个像素进入通用格式分支并调用逐像素复制。16 位 RGB565/RGB555 继续使用 v1.0.33 快速路径；自定义 BI_BITFIELDS 使用通用掩码转换。BMP 文件仍按连续行批量读取，倒序 BMP 在输出时映射到对应显示行。

改动覆盖文件管理图片预览和屏幕测试选图共用的 BMP 预览模块。JPEG/PNG 由 SDK MPP 解码，本版没有改动其核心解码器。实际速度、颜色和裁剪仍需用目标板与 SD 卡测量。

验证：Luban-Lite OS 编译和 IMG 封装通过；目标板显示效果尚未验证。
