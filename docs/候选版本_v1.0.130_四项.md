# v1.0.130 四项界面与 OTA 回刷候选版

- 设备总览的设备信息区隐藏名称编辑控件，右上角不显示系统槽状态。
- 图片和视频退出后释放其拥有的缓存，并由LVGL图像缓存回收未引用图像。
- WiFi扫描由后台任务执行，界面请求不再同步调用等待WLAN管理锁的连接状态查询；扫描结果在事件回调中集中更新。
- OTA允许版本相同或更低的OS-only已签名CPIO回刷。仍验证产品、硬件、RSA签名、CPIO CRC/白名单，并只写非活动OS槽。

采用单RODATA factory布局：OS_A/B各5248KiB，单RODATA4096KiB，DATA1024KiB；首次从旧分区布局迁移需备份DATA，AiBurn全片擦除烧录factoryIMG。

工具箱更新为0.8.38，并已完成 Windows Python 3.8 onedir 打包。D133 OS 编译完成；OS-only CPIO 已修复 ArtInChip 环境 CRC 与外层成员校验和，并通过 RSA-2048/SHA-256 验签。工厂 IMG、OTA 和工具箱包已生成并附 SHA-256。网络页面响应、PSRAM 回收效果、OTA 回刷启动以及显示界面仍需目标板确认；禁止将主机打包结果视为硬件验收。
