# v1.0.63 D133 单端口 5000

信息查询和 D133 CPIO OTA 统一使用开发板 TCP 5000。服务根据 LNET 命令号区分客户端请求：工具箱总览使用旧式 0/1 信息握手，OTA 客户端直接发送 D133 OTA 命令；上传仍执行 RSA 签名、产品/硬件/版本、CPIO 白名单校验和屏幕确认。网络设置页显示当前 IP 与 5000 监听状态，服务在创建、绑定、监听或 accept 异常后每秒重试。

电脑与板卡须经同一路由或明确配置过路由，连接当前板卡有效 IP:5000。若网络页面显示“启动失败，重试中”，查看板端系统日志中的套接字或 bind 失败提示。电脑此前地址为 192.168.18.97、板卡记录地址为 192.168.21.132，两个地址处于不同子网；交付前的本机探测在当时网络无法连通两端。检查时请确认电脑与板卡所处网络已互通。

工具箱 0.8.36 的客户端和 D133 升级页默认端口已改为 5000，并在本机安装目录替换了 Source 与 pyc 文件。工具箱仍运行旧进程时必须完整退出并重启，修改才加载。原始客户端备份在“工具箱备份/TCP统一端口5000_v1.0.63”。

构建：Luban-Lite OS 成功；OTA CPIO 与签名通过主机校验，工具箱 3.31 MiB OS 限制可接受该版本。开发板端 TCP 监听、同网段连通和实际 OTA 尚未实测。公开固件不包含本机 WiFi 密码；本机定制 IMG 另存于内部部署目录。工厂烧录前备份 DATA。
