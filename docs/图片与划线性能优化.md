# 图片与划线性能优化

- 白屏触摸笔迹按每段最多 16 个点绘制，每段仅覆盖对应的局部区域；不同笔画不再自动连接。最多保留 64 段，超出后删除最旧段，切页清空笔迹。
- BMP 按文件偏移递增读取可见区域，倒序存储时将读取行写入对应的显示行。可视行连续时避免逐行定位；裁剪或行填充导致不连续时仍需定位。文件管理和屏幕测试共用此路径。
- 屏幕测试扫描到匹配图片后复用已获得的图片头，减少 JPEG/PNG 的重复读取；JPEG/PNG 的解码和颜色转换仍由既有 SDK 路径处理。

## 板上对比

使用相同 SD 卡，在 v1.0.29 与 v1.0.30 分别从文件管理打开相同的 BMP、JPEG、PNG；再在屏幕测试目录放入与当前分辨率相同的图片并进入图片页。记录从操作到画面稳定显示的时间，并确认颜色、居中、裁剪及返回键。对白屏连续慢划、快划、抬笔后再划，检查连贯性、断笔和抬笔处是否错误连接；超过 64 段时检查最旧线段按预期消失。检查按键切页与返回键仍可用。

构建成功不代表目标板速度、触摸效果或 SD 兼容性已通过验证；本次未连接设备测量。
