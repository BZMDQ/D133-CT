# v1.0.31 普通 NOR 快速启动

专用 Bootloader 配置启用 `AIC_HMI_FAST_NOR_BOOT`。普通 SPI NOR 启动时跳过 USB Host 初始化和 U 盘自动扫描，从启动关键路径去除该连接检查的 1000 ms 超时等待。实际节省时间取决于原设备状态，尚未上板测量，不能据此承诺整机 1 秒启动。

普通 NOR 开机插入 U 盘不再自动触发升级。官方显式 BD_UDISK 启动处理、USB/UART 升级请求、USERID/强制升级判断继续保留。USB BROM/AiBurn 工厂恢复、应用 SD/TCP OTA 与原 NOR 读取时钟不受此开关影响。

此项修改在 Bootloader 中，日常只更新 OS/RODATA 的 OTA 无法替换它。需要用户手动使用配套工厂 IMG 部署；本工程不连接硬件烧录。工厂镜像包含 SPL/Bootloader、ENV、OS、RODATA 和 DATA，烧录时须按已有数据保留需求选择操作。

## 上板验证

1. 使用同一供电、屏幕、SD 卡和网络条件，分别记录旧版和新版从上电到首页首帧的时间；多次冷启动及热复位检查稳定性。
2. 确认新版普通 NOR 启动不再自动探测 U 盘升级。
3. 由用户人工进入 BROM 模式，确认 AiBurn 可发现设备；实际烧录需另行人工操作。
4. 检查 SD 文件浏览、SD/TCP OTA、按键和触摸功能。OTA/Flash 写入验收由用户在设备上执行。

源码差异和构建日志保存在 docs，原配置快照保存在本机 00_原始配置/stage_fastboot_v1.0.31。
