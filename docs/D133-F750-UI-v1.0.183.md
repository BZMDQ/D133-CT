# D133 控制终端 1.0.183

基于 1.0.182，适用于 D133CBS / D133CBV-QFN88-V1-2。首页采用 F750 风格的白色顶栏、深绿设备状态卡和三列常用应用。左上角仅保留 WINSTAR 标志。时钟、Wi-Fi 和 SD 卡显示板上实际状态。

点击「屏幕检测」或按板载 LEFT 进入纯白全屏。UP／DOWN 切换画面，RIGHT 退出。测试仅显示图案、图片及白屏触摸轨迹。图片加载期间或找不到匹配的 SD 图片时显示内置校准图。

## 文件

- D133-F750-UI-v1.0.183.img 是工厂镜像，沿用上一版 Bootloader。
- D133-F750-UI-v1.0.183.cpio 与同名 .cpio.sig 是一组 OS OTA 文件，适用于已配置同一验签公钥的设备。
- D133-F750-UI-v1.0.183.json 和 SHA256SUMS.txt 用于核对版本、大小和哈希。

本次通过了 RISC-V 交叉编译与打包、工厂镜像和 OTA 的 OS 负载比对、OTA 白名单与 CRC 校验、RSA-2048/SHA-256 验签。实体屏幕和按键尚未上板验收。
