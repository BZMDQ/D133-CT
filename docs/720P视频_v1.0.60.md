# v1.0.60 720P 视频实验版

## 格式和使用

从文件管理器选择 SD 卡中的 AVI、MP4 或 MOV，然后点击“打开”。仅支持 MJPEG 基线编码、无音频、偶数宽度，最大 1280×720；普通 H.264/H.265 MP4 需要先转换。大画面使用 SDK 的单个解码帧缓冲，LVGL 完成绘制后再交还解码器；小视频沿用原路径。大画面右上方显示的“渲染帧/秒”是 LVGL 完成绘制的频率，不等同于屏幕真实刷新率或芯片硬件峰值。

1280×720 是输入视频尺寸。1024×600 屏会按比例缩小显示。芯片手册标称 MJPEG 720P@60fps，但本固件、8 MiB PSRAM、SD 卡和屏幕组合的实际流畅度、最大码率、运行稳定性及帧交接正确性尚未经过开发板测试；内存不足或过大压缩帧可能导致播放失败。

## 视频转换

在安装 FFmpeg 的 Windows PowerShell 7 中：

```powershell
.\scripts\convert_video.ps1 -InputFile 'D:\video\input.mp4' -OutputFile 'D:\video\output.mp4' -FFmpeg 'C:\ffmpeg\bin\ffmpeg.exe'
```

脚本保留画面比例，限制为 1280×720、60 fps，转成 MJPEG 并去除音频；设置 10 Mbps 目标码率和 12 Mbps 峰值以降低 SD 持续读速压力，低帧率输入可能通过重复帧生成 60 fps。实际转码已测试：用户样片从 35.9 Mbps 降到约 13.7 Mbps，FFmpeg 报告码率控制欠载，说明 MJPEG 复杂画面不一定达到目标码率，且可能降低画质。输出可用 .mp4、.mov 或 .avi，脚本不覆盖已有文件。本次已用 FFmpeg 9.0.2 生成并检查 720P/60 fps MP4/MJPEG 测试片段；转换工具不包含在公开固件包中。另附约 10.2 Mbps 的 5 秒测试片，建议先用它检查解码与显示，再用高码率原片检查 SD 读取能力。

## 建议测试

先使用此前能播放的小视频，确认 v1.0.59 起的启动缓存调整未发生回归。然后将 5 秒 720P60 测试片段复制到 FAT32 SD 卡，播放并观察画面、渲染帧/秒、暂停、继续、返回及反复打开；再测试真实视频和长时间播放。发生错误请记录完整提示、渲染帧率、SD 卡型号和文件参数。

## 验证与升级

SDK OS 编译成功，OS 3008512 字节、RODATA 3178496 字节，均在当前 A/B 槽内。OTA 已通过 CPIO 完整性、SPL 映射拒绝、RSA/SHA256 验签和已安装工具箱的包识别；设备上的 TCP OTA、视频播放和回滚未验证。OTA 只适用于已安装新分区布局且版本低于 1.0.60 的设备，签名与 CPIO 需放同一目录。公开镜像不含默认路由器配置；工厂烧录可能初始化 DATA，请先备份。
