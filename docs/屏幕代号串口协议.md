# 屏幕代号串口协议

UART0 使用 115200/8N1，输入 ASCII 屏幕代号。CS000 对应 1024×600 LVDS/GT911；CS001 对应 WJ101E5TAAUMNG10#、ILI9881C-04T00GA、800×1280 四通道 MIPI-DSI，触摸暂时禁用。

启动时返回当前配置，例如：

```text
CS001,READY,RES=800x1280,TOUCH=DISABLED
```

发送 `CS001` 后，若需切换配置，设备通过官方 ENV API 保存设置并重启：

```text
CS001,OK,REBOOTING,RES=800x1280,TOUCH=DISABLED
```

如果 CS001 已经是当前配置，则返回 `CS001,OK,ACTIVE=CS001,RES=800x1280,TOUCH=DISABLED`。不支持的代号返回错误，不更改 ENV。

## CS001 显示配置

v1.0.38 使用 SDK ILI9881C 面板驱动的 `ILI9881C_04_DEFAULT` 匹配项。资料确认面板原生有效尺寸为 800×1280、MIPI 四通道。SDK 候选接口参数为 RGB888、Video Burst、95 MHz；H sync/back porch/active/front porch 为 10/200/800/200，V sync/back porch/active/front porch 为 3/12/1280/12。面板 RESET 使用 SDK 驱动指定的 PD.14。

获批图纸和供应商初始化参考文件位于用户提供的 WJ101E5TAAUMNG10# 资料目录；SDK 面板初始化及定时定义以随 Luban-Lite SDK 的 `panel_dsi_ili9881c.c` 为准。供应商参考 C 文件中的 SSD2828 主机代码不用于 D133 的直连 MIPI 通路。

FPC lane 顺序、极性、PD.14 到模组 RESET 的实际接线及背光仍需上板确认。当前源码编译和 IMG 封装不代表 MIPI 出图已验收。触摸保持关闭；虽然模组图纸列有 GT9271，本版没有接入其驱动和硬件配置。
