# D133-控制终端屏幕检测

首页新增“屏幕检测”入口。检测画面覆盖当前显示器的实际分辨率，不依赖固定的 1024×600 或 1280×800 常量。

## 测试页面

页面顺序循环如下：

1. 全屏白色；触摸并移动时绘制 2 像素蓝线。
2. 上半屏八色条，下半屏 32 级灰阶。
3. 黑底最外缘 1 像素白框。
4. SD 测试图像。
5. 全屏 32 级灰阶。
6. 全屏纯红、纯绿、纯蓝、纯黑。

白屏笔迹在切页时清除。纯色、灰阶、边框页不绘制标题或导航控件。

## 按键与触摸

- GPAI2 按键按下沿切页：UP 返回上一页，DOWN 前往下一页；两键采用 30 ms 消抖并循环切换。
- 触摸上下滑动也可切页，方便没有实体按键的屏幕配置。
- 在全屏测试画面左上角长按可返回“屏幕检测”说明页。此区域不绘制返回图标，避免影响色彩和边界检查。
- 只有白屏页响应触摸划线。

## SD 测试图像

在 SD 卡创建目录 `/sdcard/测试图像使用/`，放入 BMP、JPG/JPEG 或 PNG。系统在独立 RT-Thread 图片工作线程中扫描目录，只选择宽高都与活动显示器实际分辨率完全一致、且 SDK 能解码的图片。图像按 1:1 像素显示，不缩放、不裁剪。

没有 SD 卡、目录不存在，或目录中没有当前分辨率的可解码图片时，页面显示：`SD没有本机测试图片`。图片扫描和解码不会阻塞 LVGL 线程。

## 配置与验证

工程启用了 SDK GPAI2 通道供 UP/DOWN 电阻按键使用，采样通过 RT-Thread ADC 设备接口完成；未修改 GPAI、显示、触摸等 BSP 驱动源码。图片目录与解码依赖现有 SD/FATFS、LVGL BMP 与 ArtInChip MPP JPEG/PNG 接口。

编译和 IMG 封装只验证主机侧构建。上板后还需检查按键电压窗口、触摸线条、面板色值、实际屏幕分辨率、SD 挂载和图片解码结果。
