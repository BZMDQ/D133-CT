# 无线 Wi-Fi 与蜂鸣器集成状态

## 板级资源

D133CBS 开发板硬件说明书标注板载 RTL8723DS（SDIO Wi-Fi/BT）模块：SDMC0 使用 PB6–PB11，模块使能为 PD7。蜂鸣器输入为 PE11/PWM1_A，原理图标注频率 4 kHz。SD 卡使用 SDMC1，因此两者总线资源分离。

## SDK 支持边界

当前 Luban-Lite 源码的 WLAN Kconfig 仅列出 Realtek RTL8733、RTL8189、ATBM603X、ASR、AIC8800 和 HUGEIC 选项。Realtek SConscript 只会链接 `libwlan_rtl8733_*` 或 `libwlan_rtl8189_*`；当前 SDK 没有 `libwlan_rtl8723ds_e907f.a`，也没有可选的 RTL8723DS RT-Thread SDIO 驱动/固件。因此不能打开 RTL8733/RTL8189 选项来代替板上的 RTL8723DS。

RTL8723DS 需要与该芯片匹配的 RT-Thread SDIO WLAN 驱动、芯片初始化与 RF/PHY 支持、所需固件/参数，以及可供当前 E907F 工具链链接的完整源码或预编译库。Linux RTL8723DS 驱动依赖 Linux MMC、netdev 和内核工作队列接口，不能直接放进 RT-Thread 工程。缺少上述驱动依赖前，本工程不设置 `AIC_WIRELESS_LAN`，也不将 SDMC0/PB6–PB11 切换到无线用途，避免生成“看似启用但无法联网”的镜像。

收到匹配的 RTL8723DS RT-Thread 驱动和 E907F 库后，再按 SDK 已有接口配置 `AIC_WIRELESS_LAN`、`AIC_WIFI_SDMC_ID=0`、`AIC_WIRELESS_PWR_GPIO="PD.7"` 和 SDMC0，并通过 `rt_wlan` 接口实现扫描、入网、IP 状态及工具箱 TCP 8899 OTA。当前 RMII 有线 TCP/OTA 路径保持不变。

## 已集成的蜂鸣器与设备消息

`buzzer_manager.c/.h` 通过 SDK `rt_device_find("pwm")`、`rt_pwm_set()` 和 `rt_pwm_enable()` 操作 PWM1 通道 1；蜂鸣请求由 RT-Thread 工作线程异步执行。LNET 工具箱会话首次 `INFO` 和有效 OTA `BEGIN` 分别记录系统日志、更新最近设备事件并请求 1 秒提示音。新版工具箱读取设备 JSON 消息；健康检查使用 `0xD105`，不会反复触发蜂鸣。

## 验证边界

构建只能验证 PWM API、工程配置和消息协议代码可链接。蜂鸣器声响、RTL8723DS 枚举/扫描/关联和实网 TCP 仍需开发板验证；本次不会自动烧录或改写 NOR。
