# 屏幕检测多指划线

v1.0.36 将触摸 track ID 与坐标状态从 ArtInChip LVGL 触摸输入适配层提供给屏幕检测。白屏页为最多五个触点分别保留笔迹段，触点抬起后另起笔迹；多指不会共用一条轨迹。其它测试页忽略划线，左上角返回键仍由 LVGL 单指输入处理。

每段最多 16 点，总共 64 段；达到容量后复用最旧线段。LVGL 线程通过快照读取触点状态并创建/更新线对象，GT911 采集仍由原触摸线程执行。本改动不修改 GT911 驱动。

主机 OS 编译通过。需在支持多点的 GT911 屏上同时按住 2 至 5 指交叉划线、分别抬指、连续划超过 64 段，并检查轨迹是否串指、回收和触摸返回键；尚未实机验收。
