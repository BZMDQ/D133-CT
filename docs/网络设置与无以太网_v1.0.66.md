# v1.0.66 网络设置与无以太网配置

网络页保留 Wi-Fi STA 扫描、输入密码连接、最多五组保存网络，以及 TCP 系统信息和 OTA 服务状态。TCP 服务统一监听 5000 端口。

状态区将 TCP 监听和 Wi-Fi 连接拆为两行显示，并增加行高和垂直间距；TCP 行只显示监听状态与端口，Wi-Fi 行单独显示 STA IP 和连接状态，长文本按单行省略，避免相互覆盖。

固件配置关闭 AIC8800 AP 模式所需的 DHCP 服务器，保留 STA 所需的 lwIP DHCP 客户端与 netdev；GMAC0、RMII PHY、CLK_OUT2 外部 PHY 时钟和以太网静态地址配置均关闭。BSP 内按配置宏编译的通用 pinmux/驱动源文件不作修改。
