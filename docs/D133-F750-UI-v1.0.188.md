# D133 控制终端 1.0.188

基于 1.0.187。本版重排了文件管理、网络设置、固件升级、设备总览、系统信息、系统日志和应用支持。保留 F750 风格与 WINSTAR 标志，常用操作放在页面首屏，文件管理操作、升级详情和设备诊断按需展开。

首页与全部应用宫格在返回时复用，退出的应用和图片预览先隐藏，随后由 LVGL 线程回收。

屏幕检测保留 1.0.187 的纯全屏、实体按键和轮播间隔设置。USB 升级链路沿用 1.0.187。

工厂镜像为 .img。OS OTA 需要 .cpio 和同名 .cpio.sig。SHA256SUMS.txt 提供下载校验。本版未烧录，返回耗时和显示效果待实机验证。
