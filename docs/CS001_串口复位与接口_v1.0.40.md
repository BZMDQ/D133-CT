# v1.0.40 串口复位修复与 CS001 接口核对

CS001 与板载 J3 为 40 钚逐脚直连。显示数据使用四通道 MIPI DSI；屏端 2 脚为 3.3V、3 脚为 1.8V、5 脚 RESET、31/32 脚 VLED−、39/40 脚 VLED+。开发板说明书 J3 原理图将 RESET 接至 RC 网络；LED+/LED− 接板载背光网络。开发板 J3 VDDIO 连接与屏 1.8V 要求之间的兼容性尚未实测，不能仅凭相同脚号确认电压。J3 引脚表与其示意图对 D2 和 CLK 对应 MCU 引脚存在不一致，不能仅靠该资料确定信号路由或改动 PHY 配置。

关闭 FinSH 时 SDK 的 rt_hw_cpu_reset 为空实现，旧版切换命令发出 REBOOTING 后可能永久等待。此版通过 SDK 看门狗设备请求复位，并停止健康线程喂狗；同一 CS001 命令也会触发重新启动。OTA 重启共用此方法。无法启动看门狗时返回 ERR,REBOOT_FAILED。

验证：手动烧录 IMG 后，通过 115200 8N1 发送 CS001，应答 REBOOTING 后预计约 1 秒重启并输出 CS001,READY；发送 CS000 可切回原屏配置。实际复位、CS001 画面及背光均未经过硬件验证，编译成功不代表屏幕已经点亮。请勿自动烧录或擦除。
