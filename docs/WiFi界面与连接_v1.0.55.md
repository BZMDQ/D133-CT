# v1.0.55 无线网络设置

网络页面采用 Linux 桌面设置的分区布局：附近网络、连接输入、已保存网络和设备热点。无线初始化完成后自动扫描，进入页面再扫描，也可手动刷新。选择附近网络后点击“选择网络”，输入密码并连接；开放网络密码留空。网络参数通过 SDK WLAN 配置接口保存至 /data，最多五组。页面显示当前网络及保存或 DATA 不可用的状态。

修复原代码在首次连接前错误等待 rt_wlan_is_ready 的问题。SDK 的 READY 需要先完成连接和协议就绪，原先该等待会超时导致初始化退出。/data 检查现在要求实际挂载点等于 /data；不会格式化或自动清空 DATA。

构建：Luban-Lite OS 编译通过。实际无线扫描、关联、DHCP、STA+AP、断电恢复和 OTA 尚须上板验证；WiFi 凭据在 DATA 中以明文保存。本机定制镜像包含默认无线配置，不应公开。公开镜像不含该配置。工厂烧录可能改变数据，请先备份。
