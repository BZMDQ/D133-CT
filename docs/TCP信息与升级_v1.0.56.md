# D133 控制终端 v1.0.56：TCP 信息与固件升级

开发板获取有效 IP 后自动监听 TCP 5000 和 8899，绑定所有网络接口。5000 使用研发工具箱总览的 LNET 0/1 命令，只读系统信息，不提供 Key 认证；工具箱总览点击“不使用 Key”，端口填写 5000。设备信息包含型号、固件版本、运行时间、屏幕分辨率、A/B 槽位和健康标志。8899 继续提供 D133 专用 OTA 协议，要求兼容的 CPIO、RSA 签名、产品硬件与版本检查、SD 卡和开发板触摸确认，写入非活动槽，不包含 SPL、ENV 或 DATA。

工具箱操作：电脑与开发板连接同一路由器、或确认两者网段可路由；从开发板 WiFi 设置确认设备 IP。总览填写该 IP 与 5000，点击“不使用 Key”后读取信息。固件升级页面选择 D133CBS，填写开发板 IP 和 8899，选择配套 .cpio 文件并保持同名 .cpio.sig 在旁；按设备屏幕提示确认。版本必须比当前板端固件新，不能用 v1.0.56 更新已运行 v1.0.56 的设备。前提是 v1.0.51 起的 16 MiB 新分区布局，旧布局不能直接跨布局 OTA。

工具箱 0.8.36 旧 D133 客户端限制 OS 为 2 MiB，无法载入本版，请先手动安装配套客户端补丁。公开工厂镜像不含默认 WiFi 密码，本机定制镜像单独存放。凭据以明文存放在 DATA。工厂烧录可能重新初始化数据，操作前请备份。

主机验证：SDK OS 编译通过；官方 CPIO 成员、SPL 禁止映射、损坏拒绝与 RSA/SHA256 验签通过；工具箱 Python 3.8 客户端接受此包。未在开发板验证 TCP、WiFi、SD、OTA 写入和 A/B 回滚，也未验证实际工具箱 GUI 运行。5000 端口无 Key 认证，仅适用于受信任的网络；未知 Key 会明确拒绝。
