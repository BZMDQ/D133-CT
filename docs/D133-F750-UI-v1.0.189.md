# D133 控制终端 1.0.189

基于 1.0.188 修复滚动刷新、网络设置与返回、方框字和首页时钟。

- 1024×600 RGB565 配置在 PSRAM 容量满足时增加备用帧缓冲，在垂直同步时换页。备用页无法分配或面板分辨率较大时，保留单缓冲并在滚动刷新前等待垂直同步。
- 网络页从后台缓存读取 SSID，等扫描结束后更新下拉列表。固定返回按钮避开列表遮挡，实体 RIGHT 可从普通应用返回。
- 替换现有字库中缺失的间隔符。时钟按北京时间显示，通过 STA 接口校时，RTC 复位时显示 --:--。
- 纯全屏检测与原有实体键切换保留。

固件含工厂镜像及签名 OS OTA。本版未烧录，滚动、触摸和联网校时效果待实机验证。
