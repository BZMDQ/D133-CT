# 研发工具箱 0.8.38

- 更新 D133CBS TCP OTA 客户端，兼容 v1.0.130 的 D106 OS-only 直写协议。
- OTA 客户端接受签名有效的相同版本或较低版本 OS-only 固件，用于重装和回刷；仍校验产品型号、硬件型号、CPIO 白名单和 RSA 签名。
- 保留 A/B 非活动 OS 槽写入、屏幕确认、重启后版本/槽位健康确认和升级各阶段耗时显示。
- 完整包不内置用户的 TCP Key 或 WiFi 密码；Key 由操作者本地导入。

完整便携包：`downloads/ResearchToolbox_0.8.38.zip`。解压后运行 `ResearchToolbox_0.8.38.exe`。SHA-256 见同目录的 `.sha256` 文件。

该工具箱和 v1.0.130 固件的主机打包已经完成。真实设备的网络连接、回刷及 A/B 启动尚未验证。
