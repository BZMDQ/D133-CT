# v1.0.47 SD 中断等待与 BMP 阶段诊断

工厂和 OTA 配置启用 SDK 已有的 `CONFIG_AIC_SDMC_IRQ_MODE=y`。原 SD 传输等待使用 CPU 轮询；新配置使用 SDK IDMA 完成中断及信号量等待，使等待卡传输期间 CPU 可以运行转换和界面线程。未修改 SD 底层驱动、NOR 时钟或 SD 时钟。

SDK 的 IRQ 路径对单次 IDMA 完成信号使用 2000 ms 超时；这不是整个文件读取的超时。图片线程仍需等待在途读取结束才能释放缓冲，不能把应用信号量改成超时后直接释放内存。

文件管理图片加载窗口显示当前阶段和该阶段停留时间：排队、打开文件头、缓存分配、SD 读取/等待预读、像素转换、显示缓存同步。数值是当前阶段时间，不是累计 SD 吞吐或端到端打开时间。快速阶段可能来不及显示。

## 手动测试

1. 先备份配置及数据，再用 AiBurn 手动烧录 v1.0.47 工厂 IMG；此包包含首次部署用配套 Bootloader，工厂烧录可能覆盖 ENV 和 DATA。
2. 使用同一卡、同一 BMP 比较 v1.0.46/v1.0.47 的打开时间及 UI 响应。记录长时间停留的阶段和时间，检查颜色、方向、居中、裁剪、返回及重开。
3. 检查 SD 挂载、文件复制、SD OTA 和 TCP OTA，因为 SDMC 中断配置同时影响 SD 读写。测试正常读取与读取途中拔卡的错误处理。
4. 若新配置无法识别 SD 卡，可手动回退先前 v1.0.46，记录卡型号和现象；不能自动烧录或擦除。

主机编译及包校验不能证明 SD 中断在实际板上工作或图片已提速。以上硬件项目尚待验证，不保证所有卡和图片均有相同改善。
