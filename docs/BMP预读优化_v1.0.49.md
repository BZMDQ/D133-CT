# v1.0.49 BMP 预读优化

在 v1.0.48 对齐读取基础上，双缓冲线程复用上一批缓冲尾部与下一批窗口重叠的数据，从当前文件位置继续读取新数据。减少重复读取扇区及向后定位；颜色转换、尺寸适配和单缓冲回退保持原有逻辑。上一批缓冲在转换时仅被读取，预读线程复制后交接下一批。

`python scripts/verify_bmp_sector.py <BMP路径>` 使用真实 BMP 字节检查全屏、裁剪、EOF 和预读重叠窗口。用户提供的 1024×600、24 位文件，主机读取模型处理 1,843,254 字节，无额外向后定位。该检查不运行目标设备的 C 程序，不能证明实际 SD 耗时或并发稳定性。

## 手动测试

先备份设备配置和数据，再由操作者使用 AiBurn 烧录 v1.0.49 工厂 IMG。工厂包包含配套 Bootloader，可能覆盖 ENV 和 DATA。本工程不自动烧录或擦除。

使用同一张 32 GB FAT32 SD 卡和同一原始 1024x600.bmp 比较 v1.0.48/v1.0.49，记录完整打开时间以及界面的“SD 读取／等待预读”“像素转换”停留时间。另检查 16/32 位、较小图片、大图居中裁剪、连续打开、加载时返回及拔卡。实际提速、色彩及线程同步均需上板验证；如出现异常，保留现场现象并手动回退先前版本。
