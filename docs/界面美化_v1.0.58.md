# D133 控制终端 v1.0.58 界面调整

首页保持五列应用布局，移除视频播放、系统信息和系统日志入口，设备总览也不提供这两个页面的入口；页面代码保留。播放视频请进入文件管理，选择 SD 卡 AVI 文件并点击“打开”。继续沿用 v1.0.57 的 AVI/MJPEG、无音频及最大 640×480 限制。

界面使用浅灰背景、白色卡片、蓝色主操作、中性色次要操作和一致的圆角；按压颜色以 150 ms 过渡。设备总览页可启用“减少动画”，本次运行有效，重启后恢复默认。保留必要的升级确认、A/B 槽位、文件操作和状态信息。

SDK OS 编译成功；OS 3006464 字节、资源 3178496 字节，均在当前 A/B 分区内。OTA 通过 CRC CPIO、防 SPL 映射及 RSA/SHA256 签名检查，适用于已安装新布局且当前版本低于 1.0.58 的设备，不含 SPL、ENV 和 DATA。OTA 时保持签名文件与 CPIO 同目录并插入 SD 卡。

公开镜像不含定制路由器配置，本机定制工厂镜像单独保存。工厂烧录可能重新初始化 DATA，请提前备份。屏幕上的实际视觉、触摸、视频播放和升级回滚尚未在板上验证。
